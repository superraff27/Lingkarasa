# Lingkarasa Donut & Coffee

Website React (Vite).

## Menjalankan
    npm install
    npm run dev

## Build produksi
    npm run build

## Yang perlu diganti
- Gambar di `public/images/` (lihat README.txt di dalamnya)
- `WA_NUMBER`, `MAPS_URL`, dan link sosial media di `src/App.jsx`
- `src` iframe peta di `src/App.jsx` dengan link embed Google Maps asli
